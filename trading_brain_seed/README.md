# Trading Brain — seed vault

This folder is a starter **Obsidian vault** for the Futures AI Chart Copilot.
Move or copy its contents into your real vault (e.g. `Documents\Trading Brain`)
and open that folder in Obsidian.

How it fits the copilot: the app journals structured facts into SQLite
(`copilot journal ...`); this vault is where the *thinking* lives — bias,
reviews, rules, and mistakes — linked into a graph so patterns surface.
There is intentionally **no code in this vault**.

Daily loop:

1. Before the session — create a note from [[Daily Bias]] template.
2. Copilot scan fires → paste/summarize the packet into a [[Signal Note]].
3. After the trade (or the pass) — [[Trade Review]] template, link the signal
   note, tag mistakes from the [[_Mistake Index]].
4. Friday — [[Weekly Review]]: follow the links backward and update
   [[Copilot Trading Rules]] with anything you learned.
